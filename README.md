# For Vina 💌

Website ulang tahun ke-23 untuk **Vina Ayu Miranda**, bernuansa pink × biru ala Stitch.
Dibuat dengan **React + Vite + Motion (Framer Motion) + Tailwind CSS v4**, siap deploy ke Vercel.

```bash
npm install
npm run dev     # http://localhost:5173  (tambahkan ?page=1..11 untuk lompat halaman)
npm run build   # hasil di dist/
```

## Yang perlu kamu isi
1. **Lagu**: `public/audio/my-love.mp3`
2. **Video**: `public/video/a-moment-of-you.mp4`
3. **Foto**: `public/photos/{special,memories,book,her}/01.jpg …`
4. **Surat & quotes**: `LETTER` dan `CLOSING_QUOTES` di [src/config/content.js](src/config/content.js)
